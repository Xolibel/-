# Финальный комплект HaniHouse

Сайт собран на чистом HTML, CSS и JavaScript. Сборщик и установка зависимостей не требуются.

## Запуск

Открывайте `index.html` через локальный веб-сервер, например расширение Live Server в Visual Studio Code. Имя файла намеренно записано строчными буквами для совместимости с Linux-хостингом.

## Файлы, которые нужно добавить

Поместите медиафайлы в следующие каталоги:

- `assets/video/hanygo.mp4` — MP4 с видео H.264 и звуком AAC;
- `assets/video/hanygo.webm` — необязательная WebM-версия;
- `assets/images/hero.jpg` — фоновое изображение;
- `assets/images/camper-1.jpg`;
- `assets/images/camper-2.jpg`;
- `assets/images/camper-3.jpg`;
- `assets/images/camper-4.jpg`.

Временная обложка видео уже находится в `assets/images/video-poster.svg`.

## Обязательные замены перед публикацией

В `index.html` замените во всех местах:

- `+70000000000` на настоящий номер менеджера в международном формате;
- `https://www.avito.ru/your-listing` на ссылку объявления на Авито.

## Зафиксированные требования

- название компании в интерфейсе и метаданных: `HaniHouse`;
- «ХаниГоу» используется как название проекта в истории создания;
- вкладка выбора автодома расположена сразу справа от названия компании;
- требования и история открываются в доступных диалоговых окнах;
- предусмотрены звонок менеджеру и переход на Авито;
- основной экран содержит видеоплеер;
- интерфейс адаптирован под настольные браузеры, планшеты и телефоны;
- управление окнами и внутренними вкладками доступно с клавиатуры.
